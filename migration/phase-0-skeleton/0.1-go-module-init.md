## Decisions

- Module name is `github.com/visdomtech/kimi-code` (not moonshot-ai).
- The `Makefile` replaces the existing pnpm-based Makefile. The old TS targets (pnpm install, pnpm build, etc.) are no longer needed since the Go rewrite is a big-bang replacement.
- Every internal package gets a `doc.go` with a one-line package comment describing its purpose. This establishes package ownership early.
- `pkg/` is a public package for SDK consumer types (mirrors the TS `node-sdk` public API boundary).
