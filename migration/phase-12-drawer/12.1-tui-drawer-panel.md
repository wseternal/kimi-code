# TUI Drawer Panel

## Summary

A right-side split-pane drawer toggled by `Ctrl+T`, showing three sections:
- **Progress** -- lightweight plan task list (pending/active/done)
- **Tools** -- live individual tool call entries + grouped summary at bottom
- **Skills** -- accumulated skills invoked during the session

Reference: TypeScript kimi-code at `/Users/jiangzhaohua/codes/kimi-code` -- `TodoPanelComponent` (Ctrl+T), `AgentActivityView` (event fold), `ToolCall` types, `GoalStrip`.

## Phase 1: Plan Data Model

**New file:** `internal/agentcore/agent/plan/tracker.go`

```go
type TaskStatus string // "pending", "active", "done"

type Task struct {
    Title  string
    Status TaskStatus
    At     time.Time
}

type Tracker struct {
    mu    sync.RWMutex
    tasks []Task
}
```

Methods: `SetTasks`, `UpdateTask`, `Clear`, `Tasks`, `Len`, `Counts`, `Summary`.
Thread-safe via `sync.RWMutex` (tool goroutine writes, TUI goroutine reads).

**Test file:** `internal/agentcore/agent/plan/tracker_test.go`

## Phase 2: Plan Update Tool

**New file:** `internal/agentcore/agent/tools/plan_tool.go`

`UpdatePlanTool` implements `tools.Tool`:
- Accepts JSON: `{ "tasks": [{"title": "...", "status": "pending|active|done"}] }`
- Calls `tracker.SetTasks()` to replace the full task list
- Returns summary string ("Plan updated: 3 tasks (1 active, 1 done, 1 pending)")

Wire into tool registry in `tui.go` where tools are registered (alongside `BashTool`, `ReadFileTool`, etc.).
