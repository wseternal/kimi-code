## Decisions
- `KaosProcess` uses `io.WriteCloser`/`io.ReadCloser` instead of Node streams
- `context.Context` for cancellation in all async operations
- `Exec`/`ExecWithEnv` return `KaosProcess` interface backed by `*exec.Cmd`
- `Iterdir`/`Glob`/`ReadLines` return `<-chan string` (replacing AsyncGenerator)
- `Stat` simplified — uses `os.FileInfo` (no syscall.Stat_t for portability)
- `DetectEnvironment` uses `runtime.GOOS`/`runtime.GOARCH` and probes for bash/sh
- Windows Git Bash detection preserved with `KIMI_SHELL_PATH` override
- SSHKaos deferred to post-MVP
