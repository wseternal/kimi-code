# Phase 10: Gap Closure — Post-Migration Iterative Improvements

Systematic closure of all functional gaps between the TypeScript CLI and Go CLI.
Tracked in `gap.md` (10 categories, deleted in Phase 11 after gaps were closed).

## Cycle 1: Session Management

- `internal/agentcore/session/persist.go` — Session serialization to JSON on disk
- `internal/agentcore/session/history.go` — Message history with JSONL append log
- `internal/agentcore/session/store.go` — SessionStore: list, latest, fork, delete
- Modified `session.go` — Added SessionStore, auto-persist, GetLatest, Resume
- Features: resume by ID (`-S`), continue last (`-c`), fork, rename, replay, persistence

## Cycle 2: Permission Prompts

- `internal/agentcore/agent/permission/prompt.go` — Channel-based approval request/response
- TUI renders interactive approval panel with diff preview
- Session-scoped approval, auto mode (`/auto`)
- Replaces silent deny when permission chain returns `Ask`

## Cycle 3: Authentication

- `internal/cli/auth.go` — Interactive API key wizard
- `/login` and `/logout` commands with platform selection
- Auto-detect missing auth on startup

## Cycle 4: Slash Commands

- `internal/cli/commands.go` — Slash command registry (34+ commands across 5 groups)
- Session: `/sessions`, `/fork`, `/title`, `/undo`, `/compact`, `/init`, `/export-md`
- Agent: `/goal`, `/swarm`, `/btw`
- Config: `/provider`, `/experiments`, `/reload`, `/auto`, `/editor`, `/theme`, `/effort`
- Info: `/status`, `/usage`, `/mcp`, `/plugins`, `/feedback`, `/version`
- Utility: `/copy`, `/web`, `/add-dir`, `/tasks`

## Cycle 5: Mid-Turn Interaction

- Cancel current turn with Esc
- Message queue with drain (steer agent while it runs)
- Bash mode (`!command`) for quick shell commands
- Modified `tui.go` — streaming cancel, message queue, input state machine

## Cycle 6: Context Management

- `internal/agentcore/agent/context/manager.go` — Token tracking, compaction, context window
- `/compact` command for context compaction (heuristic: ~4 chars/token)
- `/undo` for reverting last N prompts
- Token/context usage display in status bar

## Cycle 7: TUI Polish

- External editor support (Ctrl-G)
- Input history (per-workdir persistence)
- File `@mention` autocomplete
- Terminal title updates, notifications
- Todo panel (always-visible task tracking)
- Activity spinner with tips during agent turns
- Step summary collapsible sections with focus navigation
- Multi-line input with newline insertion and cursor navigation
- Real-time streaming with collapsible blocks and readline bindings

## Cycle 8: Advanced Features

- `internal/agentcore/agent/goal/goal.go` — Goal tracker with system prompt injection
- `internal/cli/doctor.go` — Diagnostic checks (Go version, network, API, disk, git)
- `internal/cli/export.go` — Session export as markdown
- CLI subcommands: `doctor`, `export`, `version`

## Decisions

- **Session storage**: FileStore (JSON) over SQLite/bbolt — simpler to debug, no CGo
- **Auth**: Simple API key wizard over full OAuth device-code flow — covers 95% of use cases
- **Permissions**: Channel-based approval bridging TUI and permission system — clean separation of concerns
- **Context**: ~4 chars/token heuristic for estimation — accurate enough, avoids tokenizer dependency
- **Commands**: Registry pattern with 34+ slash commands in 5 groups — easy to extend
