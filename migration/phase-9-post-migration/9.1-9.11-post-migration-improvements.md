# Phase 9: Post-Migration Iterative Improvements

Incremental feature work after the initial Phase 0–8 migration skeleton was in place.
Each item built on the previous, evolving the Go CLI from a bare skeleton into a working interactive tool.

## 9.1: Interactive REPL

Added a basic REPL when `./kimi` is run without flags — line input, echo, quit.

- Commit: `eaf7a4ae7` — `fix(cli): implement interactive TUI shell with REPL`

## 9.2: Bubbletea TUI

Replaced the plain ANSI REPL with bubbletea + lipgloss:

- Welcome panel with project banner
- Syntax-colored output
- Slash command autocomplete
- Status bar with model and session info
- Adaptive theme colors for light and dark terminals

- Commit: `cf81b6bdb` — `fix(cli): replace hand-rolled ANSI TUI with bubbletea + lipgloss`
- Commit: `506e02bec` — `fix(tui): adaptive theme colors for light and dark terminals`

## 9.3: OpenAI-compatible Provider

SSE streaming provider adapter wired into the TUI:

- `internal/kosong/providers/openai.go` — SSE stream parsing, tool call accumulation
- Factory from config (model → provider chain)
- 14 tests covering stream parsing, error handling, token usage

- Commit: `706d84905` — `feat(kosong): add OpenAI-compatible provider adapter with SSE streaming`

## 9.4: TOML Config

Replaced `config.json` with `~/.kimi-code/config.toml` compatible with the TS CLI format:

- Uses `BurntSushi/toml` for parsing
- Supports `default_model`, `providers`, `experiments` sections
- Provider resolution from `default_model` via model → provider chain

- Commit: `34b69c611` — `fix(config): support config.toml format compatible with TS CLI`
- Commit: `867132b72` — `fix(config): resolve provider from default_model via model→provider chain`

- Commit: `94f826f2b` — `fix(kosong): normalize OpenAI-compatible base URLs with /v1`

## 9.11: Cursor Panic Fix

`clampCursor()` defense-in-depth at top of `handleKey` to prevent `slice bounds out of range [6:0]` when cursor position exceeds cleared input length.

- Commit: `0503c1981` — `fix(tui): clamp cursor position to prevent slice bounds panic on input`

## Decisions

- **bubbletea over hand-rolled ANSI** — Richer component model, community ecosystem, maintained
- **BurntSushi/toml over JSON config** — Compatibility with TS CLI's existing `config.toml` format
- **Ripgrep-backed Grep** — Performance and correctness; `rg` is a standard dev tool dependency
- **Channel-based streaming** — Clean separation of TUI rendering from agent loop execution
- **Taskfile over Makefile** — Cross-platform, namespaced targets, YAML config
