# Phase 11: TypeScript Removal — Keep Go CLI Only

Removal of ~48 MB / ~3,949 files of TypeScript code from the kimi-code monorepo.
The Go CLI (`cmd/`, `internal/`, `pkg/`) is fully self-contained with zero dependencies on TS paths.
All removals in a single atomic commit for easy rollback.

- Tagged HEAD as `pre-ts-removal` before any deletions
- Verified `go build ./...` and `go test ./...` pass with zero failures
- Verified zero Go→TS references: `grep -r "apps/\|packages/\|pnpm\|node_modules" internal/ cmd/ pkg/ --include="*.go"` returned nothing

## Decisions

- **Single atomic commit** over multiple small commits — `git revert` restores everything; no broken intermediate states
- **Delete `docs/` (VitePress)** — it's a Node.js app with its own package.json; markdown content preserved in git history
- **Delete `plugins/`** — Go code has zero references to `marketplace.json` or `plugins/`; the official plugin runs `node ./bin/kimi-datasource.mjs`
- **Delete `flake.nix`** — current 264 lines are 100% TS; a Go flake can be written fresh later if needed
- **Delete `.agents/skills/`** — all 8 skills reference TS architecture; none apply to the Go codebase
