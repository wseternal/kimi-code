## Decisions
- **DI simplified**: No decorator-based DI. Go interfaces + constructor injection. Scope struct with Register/Resolve.
- **3-level scope hierarchy**: AppScope → SessionScope → AgentScope with parent lookup.
- **Event bus**: Go generics for typed Bus[T]. MultiBus uses any for runtime type flexibility.
- **Journal**: Append-only log backed by persistence.AppendLog with atomic sequence numbers.
- **Agent loop**: FIFO turn queue via chan *TurnJob. Each turn executes steps in sequence. Steps call LLM, process tool calls.
- **Tools**: Interface-based (Definition + Execute). Bash tool uses os/exec. File tools use os package.
- **Config**: JSON-based (not TOML) for simplicity. Can migrate to TOML later.
